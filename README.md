## 🚀 Орчноо тохируулах болон Ажиллуулах (Getting Started)

Төслийг өөрийн компьютер дээр ажиллуулах алхмууд.

### Шаардлагатай зүйлс (Prerequisites)

* Node.js 
* npm run dev

### Суулгах алхмууд (Installation)

1. Репозиторыг клондох:
   \`\`\`bash
   git clone https://github.com/your-username/your-repo-name.git
   \`\`\`

2. Төслийн хавтас руу орох:
   \`\`\`bash
   cd your-repo-name
   \`\`\`

3. Шаардлагатай сангуудыг суулгах:
   \`\`\`bash
   npm install
   \`\`\`

4. Эх үүсвэрийн `.env` файлыг тохируулах:
   \`\`\`bash
   cp .env.example .env.local
   \`\`\`

5. Төслийг ажиллуулах:
   \`\`\`bash
   npm run dev
   \`\`\`

Одоо хөтөч дээрээ `http://localhost:3000` хаягаар орно.
